# Retro (Retrospectiva)

Use esta skill periodicamente ou após incidentes/atritos para aprimorar o fluxo de trabalho, ferramentas e regras do agente no projeto.

## Quando Usar
- Ao final de um ciclo de desenvolvimento ou milestone.
- Após enfrentar atrito recorrente (ex.: testes quebrando repetidamente, retrabalho, perda de contexto).
- Quando uma tarefa demorou muito mais do que o esperado por problemas de ambiente ou instrução.

## Perguntas-Chave
1. **O que funcionou bem?** Quais decisões ou práticas aceleraram a entrega com qualidade?
2. **O que falhou ou gerou retrabalho?** Onde houve ambiguidade, suposições erradas ou quebra de testes?
3. **Quais foram os gargalos?** Houve falta de testes, ferramentas lentas, documentação desatualizada ou instruções imprecisas?
4. **O que deve mudar?** Quais mudanças práticas e duradouras devem ser implementadas?

## Saída Esperada
- Sugestões práticas para atualizar `AGENTS.md`, `GEMINI.md`, scripts de automação, fixtures de teste ou configurações de CI/linters.
- Ações concretas e imediatas para atualizar os arquivos de configuração do repositório, garantindo aprendizado contínuo.
